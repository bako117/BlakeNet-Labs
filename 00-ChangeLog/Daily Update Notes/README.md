# Daily Update Notes

Day-by-day log of lab activity — what was worked on, alerts reviewed, changes made, and goals for the next day.

Each file is named by date: `YYYY-MM-DD.md`

Use the **Daily Templates** in the `Templates/` folder to create new entries.

## Documentation Upkeep
- Whenever a Lab Change is logged, the template prompts updating the relevant runbook/infra doc immediately — don't let it wait.
- Do a quick skim of `01-Runbooks & Docs/` and `05-Infrastructure/` for staleness roughly monthly, or whenever picking the lab back up after any extended break — this is exactly where drift crept in last time.
