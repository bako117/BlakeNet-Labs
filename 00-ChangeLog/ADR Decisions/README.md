# Architecture Decision Records (ADRs)

This folder tracks significant decisions made about the lab — infrastructure choices, tooling, design trade-offs, and anything worth documenting as a deliberate call rather than just a change.

Each file follows the naming convention: `ADR-001 - Short Title.md`

Use the **ADR Template** in the `Templates/` folder to create new entries.
